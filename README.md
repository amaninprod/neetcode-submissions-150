## ⚙️ How Sync Works

1. Connect GitHub at [neetcode.io/profile/github](https://neetcode.io/profile/github)
2. **Auto-commit:** Every submission on NeetCode is pushed here automatically
3. **Bulk Sync:** Push all past solutions at once
4. **Status filter:** Sync accepted submissions only, or all
